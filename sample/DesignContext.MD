# TicTacToang Visual Identity: The Neon Circuit Palette

This palette defines the high-end 2070s retro-futuristic arcade aesthetic used across all TicTacToang terminals.

## Typography

- **Headings & UI:** `Press Start 2P` (Chunky Pixel Font)
- **Body & Data:** `IBM Plex Mono` (Clean Monospace)

## Visual Effects
- **Glow:** Subtle cyan outer glows on active/primary elements.
- **Shadow:** 2px solid offset shadows (+2px +2px) for a "chunky" button feel.
- **Texture:** Scanline overlays and subtle pixel noise on large background areas.
